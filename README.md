# Smart Payroll AI

Sistema web para la gestión, procesamiento y análisis de nómina.

## Tecnologías

* Node.js
* TypeScript
* NestJS
* Prisma
* PostgreSQL
* React
* Vite

## Ejecución local

### Backend

```bash
cd backend
npm install
npm run start:dev
```

El backend estará disponible en:

```text
http://localhost:3000
```

### Frontend

En otra terminal:

```bash
cd frontend
npm install
npm run dev
```

El frontend estará disponible en:

```text
http://localhost:5173
```

Para utilizar el sistema localmente, el backend debe estar ejecutándose antes de utilizar el frontend.
